Les lignes grisées sont au-dessus de votre niveau. Les lignes marquées ESTIM. reposent sur un modèle de rendement (détaillé plus bas) ; les autres utilisent un taux d'obtention relevé sur Wowhead. Bonus AH : les prix sont récupérés en direct sur ahprice pour le marché EU PvP · Horde (valeur réelle par défaut ou prix actuel au choix). Les zones dont le taux d'obtention est connu sur Wowhead Forever sont recalculées à partir de ce taux (Déchireur de tourbillon : 67 % d'Air élémentaire ; Chouettard primitif : 32 % d'Œuf géant ; Mordeuse nacrétoile : 34 % de Viande de tortue ; Ogre Cassecrête : 29 % d'Étoffe de soie ; Vieux kodo : 36 % de Viande de kodo épaisse ; etc.). Modèles pour les lignes ESTIM. : le dépeçage compte 1,8 Cuir moyen + 0,1 Peau moyenne par cadavre (monstres 22–29), 2,2 Cuir lourd + 0,1 Peau lourde (30–39) ou 1,8 Cuir épais + 0,1 Peau épaisse (40 et plus). Le minage compte un filon tous les ~3 kobolds. Les herbes comptent une récolte par nœud (2 Tombelines ; 1,5 Pâlerette + 1 Dorépine + 0,5 Moustache de Khadgar + 0,5 Vietérule). La pêche compte un coffre par prise, contenu estimé à 30 s en moyenne. Les lignes de pêche et d'herbes comptent des prises ou des nœuds : elles tournent donc à une fraction de votre rythme de monstres tués (indiqué sur la ligne). Les calculs intègrent par défaut le temps de dépeçage (-15 % sur le rythme de ces zones) ainsi que la commission de l'hôtel des ventes (-5 % déduits de la valeur AH).
